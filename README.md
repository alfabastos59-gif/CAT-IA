# Quitério Book Buddy

Crie o projeto do assistente virtual Quitério a partir do arquivo quiterio.zip anexado.
Aplique a versão limpa em src/routes/index.tsx retirando os textos indicados para que fique mais limpo e tenha mais espaço:
1. O cabeçalho no topo com "Biblioteca Maria Quitéria", o título "Quitério" e o subtítulo "o gatinho que conhece todos os livros da estante".
2. O texto com a informação técnica de voz ("Voz: Voz 3 (Fish Audio)") abaixo da animação de onda sonora no card de status.
